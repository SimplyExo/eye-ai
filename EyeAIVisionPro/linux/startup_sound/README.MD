# Startup sound
A simple script for signalizing a user that the device is ready for use. It plays a sound on the built-in speaker right after the WiFi hotspot has started

## Installation
Just run ```install.sh``` with ```sudo```

> Note: This installation script only works for linux systems using systemd!

## Using own sound files
Replace the file ```/etc/sound/startup.wav``` with a .wav file of your choice
