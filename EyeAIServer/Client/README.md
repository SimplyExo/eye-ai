# EyeAIServer (Client)
## Nutzung
#### 1. Aktivieren des zuvor erstellten Virtual Environments:
```
source ../venv/bin/activate
```
#### 2. Starten des Clients
```
python3 main.py localhost
```
#### Info: Localhost kann durch eine IP-Adresse ersetzt werden sollte der Server nicht auf dem Computer des Clients laufen!
